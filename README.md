# Посмотри в окно

Проектная работа: CSS-оформление готового приложения для поиска видео с видами из окон по городу и времени суток.

Репозиторий: https://github.com/LiveDriv/posmotri-v-okno-ad

## Запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в папке проекта. Сборка и установка зависимостей не требуются. Для получения видео нужен доступ к API `https://v-content.practicum-team.ru`.

## Реализация

В `styles/style.css` добавлены раскладка фиксированного макета, оформление видео и карточек, обрезка длинных текстов, кастомные чекбоксы, состояния наведения, нажатия и клавиатурного фокуса. Контейнеры ограничивают область прелоадеров и сообщений об ошибке. Исходные HTML, JavaScript, шрифты и вспомогательные стили сохранены.
